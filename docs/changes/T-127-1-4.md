# Typed compile command setting metadata

The existing `compile_gate.command` definition now belongs to
`src/core/workflow-settings/compile.ts`. The read-only report adapter projects
its presentation metadata in the same interleaved position. The independent
61-setting contract still covers every label, description, flag, option and
placeholder.

The canonical default remains `__COMPILE_GATE_COMMAND_UNCONFIGURED__`. Typed
string admission and candidate normalization reuse the existing workflow-config
validator: empty or whitespace-only strings fail; surrounding whitespace is
trimmed on materialization. Legacy CLI/config coercion stays with its owner.

Frozen path/value candidates for live and template targets neither execute a
command nor approve a configuration write. The compile gate retains compile-only
command admission and fail-closed handling of the unconfigured sentinel. Existing
audited writers, schema, defaults, full-suite settings and command runners are
unchanged.

Owning regressions cover default identity, both candidate targets, normalization,
invalid typed inputs, immutable ownership and presentation-only projection.
Existing foundation, workflow-config, localization and compile command gate
tests cover the unchanged consumers and execution boundary.
