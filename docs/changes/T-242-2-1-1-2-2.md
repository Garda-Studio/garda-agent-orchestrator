# Rejection-only command data integration

The command inspector uses the accepted option decoder and program-URL helper.
Explicit PowerShell File operands retain their exact bytes, including whitespace
filenames; native-prefix normalization never removes the following source operand.
Literal option values and source arguments retain their roles. Known inline code,
normalized inline URLs and batch wrappers are rejected without executing tools.
A normal return grants no recipe, project, validation or execution authority.
