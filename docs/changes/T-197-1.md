# Immutable review verdict authority

The next-step artifact reader resolves pass and fail tokens from the current
preflight's immutable effective review lane, using the shared lane-set and context
binding validators. It no longer captures mutable workspace review contracts at
module import. Reading another workspace or resolving its review contracts cannot
change this task's verdict authority.

A present malformed, inactive, foreign or inconsistent snapshot remains blocking.
Custom tokens must match the canonical generated lane contract; missing immutable
authority cannot authorize a custom lane. Historical preflights without snapshots
retain built-in compatibility, including the reader's code-failure spelling and
the shared parser's accepted aliases.

Recognizing tokens does not establish readiness. Current context, receipt,
findings, task, tree and execution-lineage checks remain required. Missing context
or receipt stays blocked even for an otherwise recognized pass token.

Affected checks cover isolated workspaces, custom pass/fail artifacts, snapshot
hash and required-selection drift, noncanonical tokens, inactive and foreign lanes,
legacy built-ins and the existing artifact reader evidence regressions. Custom-lane
navigation is the separate sequential child T-197-2.
