# Current recipe result reader

`readValidationResult` reads one current canonical native result using the same retained-attempt authentication as result evaluation. It binds the admitted recipe, preflight and current source identities, exact attempt/result paths, canonical event and original source/output digests. Missing, ambiguous, altered or stale evidence is rejected.

Reading publishes no events or facts and preserves the producer's status, including FAILED and UNRESOLVED. It neither reruns the parser nor changes a failed result into success. Focused review and expected-red consumers remain separate work; this API alone does not close semantic or terminal obligations.

Owning integration tests use a real admitted recipe with an extensionless declared test and exercise result/output/source tampering, changed helpers and refreshed source scope. Existing evaluation/execution/CLI tests retain producer behavior.
