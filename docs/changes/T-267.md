# Native correction package versions

The native correction producer now retains each rejected and transport-selected
package under the content-addressed name already required by the retained audit.
The exact serialized bytes are preserved before the canonical package advances.
An existing snapshot is reused only when its digest matches; conflicting bytes
are preserved and publication refuses instead of overwriting them.
Loaded attempt numbers must be positive safe integers before constructing a
snapshot destination; malformed attempts refuse without advancing the package
or creating a file outside its review directory.

The audit consumer and its provenance requirements are unchanged. The regression
uses actual package persistence without the fixture's manual snapshot copy,
accepts the bound stateless correction, and checks that missing or changed
selected snapshots still block audit. Original and selected package digests
remain independently available after acceptance.

This fixes future publication. It does not fabricate missing historical packages,
rewrite reviewer reports or receipts, supersede old failures, or grant parent
acceptance. Old source-qualified correction history needs its own verified
recovery or supported fresh evidence boundary.
