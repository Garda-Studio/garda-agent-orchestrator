# Documentation-only review suite evidence

Review-context preparation follows the existing full-suite scope policy. A current compiled documentation-only scope can proceed to required independent reviews without an executed pre-review suite, even when placement is `after_compile_before_reviews` or `before_test_review`.

The exemption requires an exact task identity and preflight content digest bound to the current compile cycle. The cycle's compile timestamp matches the current PASS event; the artifact's finalization time may legitimately differ. Inspection reuses the repository's contained regular-file reader, caps the classification read at 1 MiB, and hashes the same text that is parsed. Missing, malformed, oversized, linked, off-root, foreign or changed inputs retain the normal suite requirement. The canonical policy still rejects empty scopes and documentation classifications with runtime-code, test, infra or performance execution triggers. Existing navigator compile freshness checks still apply before reviewer preparation.

Review-context configuration, placement and command checks remain mandatory. For the authenticated compiled documentation-only exemption, these fields come from current workflow configuration; an obsolete or malformed optional suite artifact retains its diagnostic state and cannot prevent reviewer routing. Code and executable test scopes still require current suite status, configuration and cycle bindings according to configured placement. Completion retains its gate-owned documentation-only not-required artifact and all other mandatory evidence; reviewers follow their generated handoff and do not execute lifecycle gates.

The regression target is `tests/node/gates/review-context/review-context-docs-only-suite-binding.test.ts`, alongside existing next-step placement and review-context tests. It covers the navigator transition to reviewer routing with missing, obsolete and malformed optional suite evidence, stale/foreign/malformed/unknown scope inputs, compile drift, execution triggers, configuration tampering and suite cycle tampering. Obsolete and malformed suite evidence still blocks executable scopes.
