before acting on repository-owned project instructions. Fresh setup begins with
the real unconfigured compile sentinel and must expose the native agent-init
recovery route. Both setup paths detect the missing bindings, admit the project
commands and roles through the ordinary workflow, verify readiness, and execute
the configured checks and role consumers.

The upgrade regression always starts from the pinned public runtime built from
repository revision `e2402152aecdcd6714f16dac70ad6f44511e3b8f`. The local archive
and lock under `tests/fixtures/npm` make this boundary mandatory without network
access or an optional environment variable. Its integrity and runtime manifest
are checked before use; an actual changed and applied runtime is required.
Both revisions use version 1.4.4, so this proves a revision/content upgrade.
The package contains no private workspace state, history or permission receipts.
Each test creates its own ordinary installation and authentic task history.

an unrelated task and the exact operator notes. Those remain preserved alongside
project files, settings, permissions, active task entry, history and staged and
unstaged work through update, setup, checks and repeat update. Managed queue
preamble refreshes are permitted; operator-owned queue content is compared.
