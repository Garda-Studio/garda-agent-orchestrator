# Technology-neutral activation qualification

The qualification suite exercises the existing audited version-one declaration,
native task/preflight, recipe command, real process, canonical result and semantic
obligation readers in isolated repositories. It covers root files without a
conventional project manifest, package-local monorepo cwd, an extensionless custom
driver and literal Unicode case selectors. The driver checks the current product
input against the declared expected value; opaque output remains UNRESOLVED.

Successful execution does not supply independent semantic review or task DONE.
Missing real review reports keep terminal closure open, changed source invalidates
the projection, and unsupported declaration versions preserve existing settings.
Fixtures use installed local tooling and make no foreign-platform acceptance claim.
