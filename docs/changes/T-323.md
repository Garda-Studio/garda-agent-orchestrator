# Cancelled output delivery

Streamed subprocess output remains captured when cancellation happens before
delivery to an output sink. New sink writes are not started after cancellation,
and a drained pipe keeps its existing completion handling.

Failures from a pending sink write remain visible, including write timeouts and
storage errors. The regression cancels from the stdout callback before delivery;
the owning suites retain timeout, disk-full, byte-preservation and decoding checks.
