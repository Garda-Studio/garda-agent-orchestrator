# Compact disposable retirement intent

`prepareOwnedDisposableArtifactRetirement` persists a compact PENDING intent for
an explicitly confirmed exact preview digest. It reconstructs authenticated
committed closeout, sealed dead local ownership, the native run, bounded tree
inventory and current dependency authority before publication.

The protected producer namespace retains only selection, closeout, identity,
hash and byte-accounting metadata. Authentication uses the existing private
producer key with a distinct journal purpose. The journal binds its own ordinary
file creation identity; copying signed bytes cannot adopt a replacement object.
Missing keys and malformed, stale, foreign, linked or shared metadata stay
protected. Pending intent preserves payloads and provides no removal authority.

Publication reuses canonical lifecycle and producer-writer locks, checks their
generations and revalidates native proof and key identity. Metadata is fsynced
and closed before atomic publication; directory synchronization follows the
existing filesystem helper's best-effort portability policy. Interrupted
metadata remains protected for diagnostics. Repeated preparation reuses the
authenticated current journal. Read-only inspection checks the same current
proof and bounded persisted bytes.

The existing preview fixture is shared with journal tests while retaining all
preview callbacks. Targeted checks cover compact readable history, preservation,
confirmation, caller proof, sparse IDs, stale selection, tampering, replacement,
unsafe storage, bounded reads, missing key, WIP drift, lock loss and fsync failure.
Acceptance execution is native Linux; platform coverage is recorded separately.

Linked balanced children own exact contained payload removal and interrupted
retirement recovery before the parent cleanup contract can complete.
