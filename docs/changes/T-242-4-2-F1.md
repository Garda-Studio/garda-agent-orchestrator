# Recipe evidence overflow

Bounded focused evidence selection now counts native recipe results in its surplus scan as well as its primary scan. Eligible omitted results set `truncated`, allowing the existing review renderer to show its omission warning.

Surplus recipe eligibility uses the same authenticated current-result reader and declared test scope as retained entries. Altered, stale and non-PASSED results cannot create eligible overflow. The legacy cheap surplus check, entry limit, candidate scan limit and task/cycle checks remain unchanged.

The regression evaluates two real admitted recipes and checks a one-entry selection. Its initial failure showed one counted candidate instead of two. After selection, it alters only the omitted result artifact to verify that invalid surplus does not produce a false truncation signal. This addresses the grouped code, refactor, API and test findings from the parent task with one repair.
