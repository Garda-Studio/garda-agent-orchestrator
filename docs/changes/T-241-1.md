# Task-scoped test-selection configuration

`task_test_selection.require_operator_confirmation` is a strict JSON boolean.
Fresh configuration and legacy configuration that omits this section default to
`false`; an empty section uses the same default. Template updates preserve an
explicit `true` or `false` and all existing gate settings. Explicit nulls,
strings, numbers, unknown nested keys and case-mismatched known keys are rejected.

This bounded child establishes the typed configuration and validation contract.
The existing audited selection route retains its current confirmation behavior
until the separate admission child consumes this setting. CLI/UI exposure,
translations, current-task bindings and managed guidance remain separate work
packages. The permission applies to task-scoped test selection; it cannot disable
the test gate or change compile commands, timeout, retry, profiles or review rules.
