# Independent native case semantics

Current native command records, actual output and contained source/case identities can now form one immutable case obligation without a runner-name, filename or report-format prerequisite. Projection authenticates the actual current native process; a source hash and exit zero leave case results unresolved.

Independent review coverage carries a separate case resolution bound to that exact source, process and output. Resolved outcomes quote actual retained output and explain the selected case mapping. Unknown, missing and skipped cases remain open at terminal closure. Changed source/output and replayed bindings invalidate resolution. Output/source reads are shared within the inspection batch and rechecked afterwards.

The report schema and generated reviewer template preserve this contract without supplying a task verdict. These prerequisites expose no per-project mode switch. Normal universal quality-to-review-to-terminal activation belongs to the linked T-259-4 consumer package; this change alone does not claim ordinary activation or current OnlineStore acceptance.
