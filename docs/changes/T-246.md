# T-246: Retain real exited producer identity in Windows fixtures

The test-only producer helper starts the actual Node child through existing
Windows PowerShell and .NET process APIs. It retains the native process handle
after genuine exit, preventing PID reuse during later ownership proof reads.
The returned stdout, stderr, PID and exit status come from that child.

Test cleanup releases the handle and removes the helper's private temporary
directory. The supervisor also observes a retained handle to its Node owner and
has a finite retention deadline. Child execution and output completion are
bounded; timeout remains a failed child result. Other platforms use ordinary
`spawnSync`. No production ownership guard or identity schema is changed.

Owning tests cover real output/environment/cwd, nonzero exit, timeout,
Windows process churn and native cleanup. This helper is separate from the
preserved C1 source candidate: integrating that candidate still needs current
compatibility checks and its original owning tests. This task adds no CI,
publication, binary dependency or native addon.
