# T-265: repeated audit of an empty staged no-op

A completed, authenticated no-op with no staged changes could publish null
complete-scope hashes. The next audit rejected those same hashes as post-DONE
drift even though the working tree was clean.

The closeout producer now computes the canonical empty path-list and worktree
content fingerprints for that empty staged scope. The existing drift consumer,
no-op authentication, nonempty scope handling and rejection of invalid hashes
are unchanged. No saved task artifact is rewritten manually.

The regression materializes the authenticated no-op closeout, repeats audit and
navigation, and checks that the original closeout bytes remain unchanged.
Existing canonical-scope tests retain the nonempty and forged-hash controls.
