# Native subprocess termination facts

The existing argv-based `spawnStreamed` result now retains an optional `terminationSignal` from the actual child close event. Ordinary exits and cancellation before launch keep their previous result shape; no signal is inferred from an exit code, timeout or cancellation flag.

The legacy nonnumeric-exit classification remains `exitCode: 1`. Output capture, process-tree cleanup, timeout and cancellation behavior are unchanged. A real-process regression compares the reported signal with the original child event on the current platform.

This supplies a factual host observation for later frozen recipe attempts; it does not execute project recipes, accept opaque test output or close semantic obligations.
