# Structural boundary source evidence

Boundary assessment can bind explicit declared sources and opaque case IDs to retained file identities without requiring conventional test names, directories or extensions. It reconstructs regular contained file bytes through the existing identity reader and rejects missing, ambiguous, substituted or changed bindings. Reads have finite reference and byte limits.

Structural BOUND describes source identity only. Semantic status remains PENDING_INDEPENDENT_REVIEW for every declared assessment. Unknown syntax is UNRESOLVED. The optional javascript-test adapter retains disabled, inert and forged-case rejection diagnostics; an assertive declaration still does not prove execution or semantic relevance. Existing legacy assessment and JS diagnostics remain unchanged when declared options are absent.

Owning regressions use root files, Unicode paths and Java/Python/Go/Rust/unknown source fixtures as structural data, without claiming native execution of those languages. Governed phase consumers, independent semantic closure, terminal checks and contract activation remain separate T-242 tasks.
