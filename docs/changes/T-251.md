# T-251: test review with ordinary change documentation

Test changes accompanied only by safe ordinary documentation now retain the test-only review scope.
Their full file set and documentation remain in preflight and review coverage; test review remains required.
Ordinary documentation no longer introduces a separate code review for an otherwise test-only change.
Explicit code-review requests and existing source, configuration, unknown-file, sensitive-documentation and protected boundaries remain unchanged.
Native regressions verify the final review snapshot for balanced, fast and strict profiles, including forced code review.
