# Admitted Recipe CLI And Result Evaluation

`gate run-intermediate-command --task-id <task> --recipe-id <recipe>` executes only an admitted frozen argv recipe. Free-form command, timeout, output, scope and event-root overrides are rejected; existing command routes retain their original eligibility and artifacts.

The separate immutable result authenticates the canonical completed attempt, current snapshot, retained source/output hashes and exact declared case selectors. Supported flat TAP requires a nonempty exact plan, unique cases and no skipped targets. Opaque or unsupported semantics remain unresolved. The original attempt retains null cases and its actual host outcome.

Expected-red additionally requires the native test-only classification, exact TASK declaration and changed declared test targets. Only a real target failure with a nonzero ordinary exit is accepted; timeout, cancellation, signal, truncation or identity violations are failures. Result adaptation does not establish project eligibility or close independent semantic and terminal obligations.
# Frozen task classification

Expected-red reconstructs test-only scope using the authenticated native task's frozen review-trigger policy, preserving custom test paths after global policy changes. The CLI regression exercises a real declared target failure under that frozen policy.
