# Coverage evidence lookup cost

Coverage evidence validation indexes expected obligations once per report and
reuses the existing ordinary evidence path set for file, boundary, and category
entries. Validation entries retain their own bound-source exception; notes,
findings, and residual risks keep the ordinary domain. Duplicate expected IDs
retain the previous first-match lookup behavior. No cross-report cache is used.

The owning schema test measures actual array reads and path insertions in an
isolated process at two workload sizes. Before the change, the smaller case was
valid but performed 595 obligation reads and 1,248 path insertions; the bounded
expected-red gate recorded its failing operation-count assertion. Existing
coverage-domain and malformed-evidence tests remain part of required validation.
