# Clean-checkout CI consumer repairs

Validation fixtures use pinned compile programs and genuinely malformed command
syntax for rejection checks. They retain compile side effects, ownership refusal,
closeout drift and interrupted-audit assertions. Parent navigation checks require
the accepted aggregate audit after child completion, and protected recovery starts
with task entry when its task-mode artifact is absent.
The empty-scope review scenario explicitly declares its code and test lanes.

Read-only next-step inspection shares one TASK.md content snapshot across review
lanes. Each reader receives independently parsed entries. The snapshot expires when
the synchronous inspection returns or throws; deferred reads and effect execution
read the current queue. This removes repeated expected-RED declaration reads
without changing validation authority or publication checks.

Malformed workflow configuration still blocks classification. Its JSON error now
identifies workflow-config.json when project-validation role reconstruction is
the first consumer.
