# Native child Git source provenance

`validateNativeChildGitSource` corroborates an explicit commit, tree and single-parent (or root) identity against the exact local Git workspace. It rejects inherited repository environment overrides, graft ancestry, unrelated history, missing objects and changed object bytes.

Ancestry commits and the accepted tree are read in one bounded raw-object batch. Each typed object digest is recomputed, the initial tree and contiguous parent-header block are checked, and HEAD is rechecked before returning. Misplaced reserved headers are rejected rather than interpreted as native ancestry. Git subprocess output and execution time remain bounded.

This Git-only proof does not authenticate a task SOURCE event, reuse an old review, accept a decomposed parent, or discharge memory and other task obligations. The existing contained JSON proof reader is unchanged. Authenticated SOURCE consumption belongs to the next existing child.

Regressions use ordinary isolated Git repositories, including replacement of loose commit/tree bytes, inherited environment, graft ancestry and incomplete/oversized batch frames. Platform results are reported from actual execution only.
