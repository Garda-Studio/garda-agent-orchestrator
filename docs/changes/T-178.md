# T-178: usable native no-op preflight binding

`record-no-op` now admits a current authenticated zero-diff preflight before
publishing its PASS artifact, metrics or `NO_OP_RECORDED` event. Omitting
`--preflight-path` resolves the latest successful native classification for
the same task. Explicit paths must match that classification and resolve to
an existing regular file inside the repository.

Admission reuses the native preflight schema, current POST_PREFLIGHT rule
binding and scoped Git snapshot contracts. Missing or foreign task identity,
previous task cycles, older paths, payload drift, failed or pending
classification, malformed zero-diff metadata and newly introduced source
changes return an actionable error before publication. Rejected replacement
attempts preserve the existing artifact, metrics and event bytes.
Case-distinct copied files cannot substitute for the native classified file.
The preflight input, artifact output and enabled metrics output must have
distinct physical paths and file identities, including existing hard links.

Artifact fields, classifications, successful output and the compatible pure
artifact constructor remain unchanged. A valid no-op continues the existing
compile and review policy; it grants no permission to skip required gates.
Navigator, review, queue-sync and completion consumers are unchanged.

The test-first baseline used genuine native entry, startup diagnostics,
classification, rule binding and record-no-op calls in real Git fixtures.
Its final bound run produced 13 behavioral assertion failures and 2 passing
controls on the accepted production base. Earlier compiler/setup failures
and an incorrect positive-route expectation were preserved separately and
excluded from that claim. The final regressions also check pending
classification and tampered timeline rejection. Linux execution is the
available platform; native Windows/macOS coverage remains unverified.

The change does not introduce a transaction across artifact, metrics and
timeline publication or a new guarantee against concurrent external writers.
