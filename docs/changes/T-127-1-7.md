# Typed scope-budget control metadata

The eleven remaining scope-budget definitions now belong to
`src/core/workflow-settings/scope-budget-controls.ts`. Together with the four
accepted legacy maxima they own exactly fifteen existing definitions. The
read-only report adapter preserves the interleaved catalog positions and the
complete independent 61-setting presentation contract, including the legacy
action's `editable: false`, profile placeholder, descriptions and scalar bounds.

The existing workflow owner supplies defaults. Typed candidates accept primitive
booleans, canonical action enum values, dense string profile lists and safe
integers within the current presentation bounds. Profile normalization delegates
to the existing guard owner: names are trimmed, lowercased and deduplicated,
unknown legacy names are retained, and empty normalized lists use its existing
fallback. The public legacy parser and guarded CLI/config writers are unchanged.

Live/template hooks return only the selected frozen field candidate. They do not
write configuration, clamp companion thresholds, change WARN/BLOCK evaluation,
or confer permission to edit compatibility-only action policy. Existing guarded
writers retain cross-field validation, profiles, frozen policy and audit authority.

Tests cover every definition/default/boundary, invalid primitive and sparse-list
inputs, profile normalization and isolation, the disjoint fifteen-setting union,
immutable candidates, presentation mutation isolation and the complete report
contract. Existing foundation, config, localization, legacy maxima and guard
checks cover unchanged consumers and policy semantics.
