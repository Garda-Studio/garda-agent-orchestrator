# Intermediate validation source observations

New native intermediate-command attempts record `source_composition` beside the
original command, preflight/coverage references, output hash and actual outcome.
The event binds this additional metadata with `source_composition_sha256`.

Each observation identifies the actual Git workspace, commit, tree and tracked
or visible untracked status. Ordinary TASK and workflow-config bytes are hashed
through bounded descriptor reads that preserve path identity and reject links.
Snapshots run before and after the command; no prior attempt is rewritten.

`STABLE_CLEAN` means those observations agree and both worktrees were clean.
`CHANGED_OR_DIRTY` and `UNAVAILABLE` withhold composition eligibility, while the
command's success/failure and timing keep their existing meaning. Observation
failures retain bounded diagnostics; nongit command behavior remains supported.

This metadata is not suite PASS, child acceptance, WIP authority or parent audit
acceptance. The owning audit must authenticate the original validation contract,
native attempt and output, executable/source compatibility, accepted children,
preserved WIP and current parent memory separately. Historical failures remain.
