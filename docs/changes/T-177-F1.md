# Maven project directory spellings

Focused review validation accepts contained Maven project directory operands with
trailing separators, including `-f "tests/maven project/"`, and explicit repository
root operands such as `-f ./` and `-f .//`. These spellings resolve to the same single Java test
as the corresponding directory or POM operand.

The command still requires offline mode and a concrete test selector. Absolute,
empty, traversal and linked-project operands remain rejected; normalization does
not make slash-only operands select the repository root. Existing quoting, Maven
layout, target identity and output-option restrictions remain in force.

Regression coverage exercises focused report validation and native result
ingestion, preserving the original command and diagnostics. Parser-only fixture
admission does not establish Maven or JVM execution. This Linux environment has
no local Maven executable; the existing actual-Maven test reports that limitation
as a skip. Windows and macOS execution are unverified.
