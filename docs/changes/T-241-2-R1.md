# Safe ignored task-selection configuration compatibility

The accepted typed `task_test_selection` default changed the generated workflow
configuration's top-level keys. The ignored-config compatibility guard retained
the older keyset and rejected its own default baseline before inspecting a
candidate. That also blocked ordinary task entry from valid legacy settings.

Recognize the new optional section while preserving its strict boolean contract.
Legacy omission and an empty section keep the autonomous default; explicit
`false` and the more restrictive `true` choice remain unchanged. Malformed
values, unknown and case-mismatched keys remain unsafe. Every existing restriction
on unrelated protected settings still applies, and native task entry freezes the
accepted bytes so a later direct permission edit remains a protected change.

This bounded prerequisite repair does not implement or complete CLI selection
admission. The original task's source WIP was captured and suspended natively;
it must resume with current gates and independent reviews after this repair's
own acceptance and supported executable refresh.
