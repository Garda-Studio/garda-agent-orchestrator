# Native final-source composition proof

The decomposed-parent proof owner can now inspect a retained native intermediate
command against the caller's original required command, coverage identity and
exact final Git source. It authenticates the workspace signature and latest
current-cycle successful event, then checks stable clean source, task/config
bytes and retained output. Failed, cancelled, timed-out, expected-red, unsigned,
foreign, stale and altered records remain ineligible.

Current-source inspection also rejects index flags that conceal tracked edits.
Each command artifact must have one timeline occurrence, and its authenticated
generation time must belong to the selected cycle before its native event.
It must also follow the preceding invocation event for that command, so changing
JSON formatting and the retained file path cannot revive a superseded success.

The reader is read-only. Bounded ordinary-file acquisition is shared with the
existing child proof reader; source, authority, output and timeline are checked
again before returning. It neither executes commands nor signs old attempts.
Its result proves process execution only. Child source acceptance, independent
semantic review, parent obligations and the parent-audit caller remain separate.

The owning tests execute real native commands in isolated Git workspaces and
exercise the rejection paths. Validation on each available platform is recorded
in native task artifacts; no unavailable platform or historical parent PASS is
inferred from these fixtures.
