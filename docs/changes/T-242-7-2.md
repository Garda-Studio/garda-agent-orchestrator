# T-242-7-2 — Canonical declared validation review projection

Declared validation targets now have one bounded projection for review consumers.
It reads the exact contained preflight artifact, authenticates its effective
review snapshot against the existing frozen policy and current catalog, and
reuses canonical quality-phase reconstruction. Missing, altered, stale or
superseded execution evidence rejects the projection. Custom preflight filenames
remain bound to their actual bytes; there is no guessed default artifact.
Native recipe freezing and event inspection use the existing authenticated
current-preflight resolver, so a stale default-named artifact cannot replace the
classified file. Standalone non-executing authority freezing remains compatible;
execution still requires an active authenticated native timeline.

The projection retains every exact target/source identity, attempt and result
binding together with the phase digest. An opaque observed result remains
`UNRESOLVED`, with independent semantics pending. Required built-in code/test
lanes must be capable in the authenticated snapshot; optional lanes and disabled
capabilities cannot waive this requirement. Existing explicit task-required
selection remains valid when its capability is enabled.

Projects without declarations retain an empty target projection. This primitive
does not activate recipes, assert project eligibility, promote parser output or
close the parent task. Native review consumers remain T-242-7-3; terminal checks
and general activation remain T-242-8 and T-242-9.

Validation uses the existing native declared-review fixture and policy suite,
including genuine test-first failures before production changes, opaque targets,
custom preflight naming, mutated artifacts/maps, superseded execution and legacy
compatibility. Current owning checks, typecheck, independent reviews and native
closeout remain mandatory.
