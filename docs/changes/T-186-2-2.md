# Sealed disposable artifact preview

`previewOwnedDisposableArtifacts` accepts the canonical workspace and bundle
roots, an exact task id and a nonempty unique bounded list of registration ids.
Selection arrays must be dense string IDs; missing elements are rejected before
any IDs, partial items or compact evidence are published in the response.
It returns `READY` with a deterministic ownership digest only when every selected
root has authenticated current-run ownership, a seal and a positively known-dead
local producer. Missing, foreign, occupied or unverifiable owners remain protected.
The preview neither deletes files nor wires cleanup into native closeout.

The completed task must have current committed accepted source scope, native
successful closeout and verified compact ledger with intact canonical artifact
references. A mutable DONE row or an old successful receipt cannot substitute
for this proof. Preview retains ledger, timeline, review and final-report bytes.

Each root inventory binds exact contained paths, creation identities, current
file identities, content hashes and byte counts. Links, shared files, nested
repository metadata, replaced roots and resource-budget overflow block the whole
selection. Repository protection includes bare layouts without a `.git` entry
and recognizable linked/reftable metadata, regardless of the containing name,
including the owned root itself. Selection order does not alter the digest; payload or dependency drift
does. A later removal implementation must reconstruct and revalidate this proof.

Dependency checks include canonical unfinished queue rows and native timelines,
follow-ups, WIP references and separate worker inventories. Selected producers
must already be dead. Unauthenticated separate worker state and WIP requiring
retirement or recovery remain protected. The authority inventory is bounded and
revalidated before publication, including namespace absence and directory changes.
WIP JSON and JSONL use the same bounded decoded-content matching as native
evidence, with case-insensitive extensions. Escaped paths, hashes and task ids
retain their dependencies; malformed structured recovery metadata blocks preview.

References to selected raw paths or hashes in task-owned native evidence block
preview. A verified compact ledger alone does not migrate hash-bound raw evidence.
This policy does not yet admit a compatible migration proof format: existing raw
references always remain protected, including self-declared migration claims.
Caller-selected paths, owner overrides and success authority are not accepted.

The tests use real temporary Git repositories, native audit/ledger fixture
materialization and actual exited producer processes. They cover dry-run byte
accounting, deterministic order, preserved compact readability, native proof
failure, dependency blockers, unsafe trees (including real bare repositories)
and stale snapshots. Current execution
coverage is Linux; native Windows checks remain separate.
