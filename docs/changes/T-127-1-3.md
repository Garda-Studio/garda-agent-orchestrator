# Typed optional-quality setting metadata

The two existing `optional_quality_checks` scalar setting definitions now belong
to `src/core/workflow-settings/optional-quality.ts`. The report adapter projects
their existing presentation fields in the same positions, preserving the full
61-setting metadata contract. Stable ids, keys, flags, labels, descriptions,
options, order and cadence bounds remain compatible.

Defaults come from the canonical workflow defaults: advisory checks enabled and
a review-failure cadence of three. Typed primitive admission and candidate
materialization delegate to the existing workflow-config validator. Cadence
remains a safe integer from 1 through 100; strings and other coercions are not
typed manifest values. Existing CLI/config parsing retains its own contract.

Materialization returns frozen path/value candidates without writing config,
approving operations, running checks or creating evidence. Mandatory gates,
rule ownership and review-failure counting retain their existing behavior.
`optional_skill_selection_policy`, rule catalogs, protected settings and audited
writers remain with their current owners.

Owning tests cover exact defaults, both materialization targets, scalar boundary
rejections and immutable ownership. The independent 61-entry report digest and
interleaved order check all presentation fields. Foundation, canonical workflow
config, localization and accepted full-suite family tests provide regressions.
