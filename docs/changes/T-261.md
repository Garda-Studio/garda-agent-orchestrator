# Suspended parent navigation

An authenticated split-required decision now routes before stale parent scope
refresh. Native WIP suspension restores original source bytes, so the old parent
preflight naturally describes a different workspace. Refreshing that obsolete
scope prevented the gate-owned transition to DECOMPOSED and left implementation
ownership reserved against the child.

The change retains decision/task/profile authentication, supported WIP capture,
exact child linkage and native status transition. It does not hand-edit statuses,
change grants or authorize old evidence as current execution. The owning
regression captures real fixture WIP, links children after suspension, and checks
child routing while preserving original preflight bytes and a single manifest.
