# Native parent memory evidence paths

Parent obligation qualification now resolves the normalized memory artifact path
before passing it to the strict filesystem readers. On Windows, the native
memory evidence API returns forward separators while the transaction reader
expects the platform path representation; this previously rejected an ordinary
unchanged artifact as an unsafe transaction path.

The existing bounded ordinary-file, containment, hash, native event identity and
read-stability checks remain in place. This changes no memory producer, workflow
configuration, historical evidence or parent acceptance policy.

The owning regression uses the normalized path and verifies qualification without
changing the artifact or timeline. It first failed on Windows before the fix;
the existing invalid-memory and timeline cases remain in the same owning suite.
