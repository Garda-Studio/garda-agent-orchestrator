# Guarded decomposition profile contracts

Guarded decomposition now accepts a work-package contract with `schema_version: 2`.
Every package must explicitly declare the current frozen parent profile. A balanced
parent therefore creates balanced children, including the proposed-child evidence
and the locked native queue transition. A missing or foreign profile blocks the split.

Use the existing `gate record-strict-decomposition-decision --decision split-required`
command with `--task-profile` and `--work-package-contract-path`. The structured input
keeps the existing `finding_obligations` and `work_packages` fields; version 2 changes
the child-profile authority rather than adding a command flag.

Version 1 retains its strict-child contract, including historical balanced parents
that deliberately declared strict children. Existing finding-source hashes, review
obligation unions, exact child IDs, child quality, WIP authentication and containment
remain required. Unsupported versions and mismatching proposed-child metadata are rejected.

This is the linked prerequisite repair for T-197. It does not implement review-lane
navigation or complete the original task. Validation covers the decision contract,
actual CLI admission, native WIP suspension and queue transition, profile drift and
legacy strict compatibility in the three owning Node test targets.
