# Authenticated new source-composition records

New intermediate-command records identify their native producer and actual
generation time. A successful, non-stopped attempt with stable clean before/after
source observations can authenticate its exact command, task, output and source
record through the existing audited workspace-local ON authority. The output
digest and byte length must match the output produced by that attempt.

Missing, unaudited or disabled authority, dirty/changed/unavailable source,
failed validation, timeout, cancellation and expected-failure attempts remain
unsigned. Optional authentication errors retain the actual command outcome and
record a bounded diagnostic; they provide no composition-proof authority.
Existing attempts are retained unchanged, including older unsigned records.
Workspace identity and native key renewal prevent foreign or stale signature
replay. An ephemeral authority stamp uses the existing native signer before
execution and is compared with current audited authority after record signing.
Same-value ON renewal or OFF/ON across execution or signing keeps that attempt
unsigned, even when workflow configuration bytes remain identical. Neither the
private key nor the ephemeral stamp is copied into the attempt record.

This producer supplies record integrity. Aggregate parent acceptance still needs
its owning proof consumer, authenticated child/source evidence, complete original
validation targets, preserved WIP and genuine parent-memory obligations. An
intermediate success or signature does not resolve a historical parent failure.

The owning retention regression uses real Git workspaces and native ON/OFF
grants. Before implementation, its native expected-red run produced 34 tests,
31 passes and three missing-authentication assertion failures, without compiler
errors, timeout or cancellation. Current validation uses the audited retention,
intermediate-wrapper and focused-evidence targets. Linux execution is local;
Windows and macOS remain unverified.

The first code review identified in-flight grant renewal. A genuine native
focused reproduction then produced 36 tests, 35 passes and one renewed-authority
assertion failure while proving identical configuration bytes and stable clean
source. The correction also covers renewal at the final signing boundary;
current compile, suite and fresh reviews must validate the corrected scope.
