# Fresh completed-evidence Git query cost

A completed-evidence batch uses the HEAD already read by its initial fresh
workspace fingerprint to verify committed trees and blobs. Before any result
is returned, the independent final fingerprint still rejects HEAD or index
drift. Each invocation starts a new batch; no eligible proof is cached across
operations or supplied by callers.

A factory-authenticated workspace Git generation whose canonical classification
has no changes returns empty numstat rows without another Git process. Dirty
generations retain the ordinary numstat command and its failure behavior.
The generation remains local to one immutable snapshot request.

Full before/after workspace reconstruction, Git configuration comparison,
queue and evidence hashes, accepted scope, closeout/ledger authenticity and
committed blob verification remain mandatory. Mutation callers still revalidate
under their existing locks. Timeouts, retries and operator authority are unchanged.

The test-first regression forwards all actual Git commands and checks two HEAD
queries per batch and no numstat query for a clean generation. It also checks
fresh rejection after a successful previous call. Existing HEAD, index, worktree
and Git configuration drift tests remain in the affected suite.
