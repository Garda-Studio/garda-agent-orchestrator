# Exclusive full-suite run ownership

Run-marker admission now creates the canonical file exclusively. Existing live,
stale, malformed and indeterminate records remain intact and require the existing
native inspection/recovery path; ordinary admission never removes them.

The writer's returned marker is an issued process-local handle. The sole full-suite
caller retains it for child updates and terminal cleanup. JSON copies and earlier
handles carry no mutation authority. Each operation checks retained parent and
ordinary single-link file identity, a held descriptor and exact current bytes.
Child updates publish complete JSON with a same-directory atomic rename and move
the held lease to that object. Failed admission never enters another run's finally
cleanup. Interrupted initial publication is preserved for explicit recovery.

The schema-1 inspection/recovery metadata and child identity fields remain
compatible. Existing native recovery remains independently audited. Cooperating
writers serialize through the existing mutation lock; arbitrary external path
replacement between final filesystem syscalls is not claimed atomic.

Focused owner regressions, existing recovery checks and CLI transaction checks
run on Linux. Windows execution remains unverified.
