# Nonblocking timeline proof acquisition

`captureTaskTimelineRead` previously opened the final timeline pathname with a
blocking read after its ordinary-file checks. On POSIX, replacing that final file
with a writerless FIFO could stall `next-step` before descriptor validation ran.

Descriptor acquisition now uses read-only, nonblocking and available no-follow
flags. Existing descriptor/path identity, containment, exclusive-link,
write-authority, final revalidation and byte-budget checks remain unchanged.
Uncertain proof produces an invalid snapshot without exposing payload or a hash.
Timeline append, bounded-tail reads and deep WIP capture/restore are unchanged.

The owning regression seeds three actual native events, replaces only the final
file at descriptor acquisition and bounds its isolated child externally at three
seconds. It requires prompt invalidation, the same parent directory dev/ino and
byte-identical original JSONL. The unchanged regression first produced an
authenticated expected-red test failure on the accepted predecessor runtime.
Existing capture-count and short-read checks recognize read-only nonblocking
descriptors; the unrelated bounded-tail counter remains unchanged.

The affected command covers native timeline, parent continuation and quality
consumption tests. Windows skips the POSIX FIFO case; Windows and macOS execution
are not claimed. Producer acceptance does not establish C3 consumer acceptance:
the consumer still needs its own bounded import, gates and native recheck.
