# Exact declared validation coverage binding

Coverage contracts can retain each canonical declared target, its literal selector,
source identity, frozen snapshot, observed attempt and result. These fields enter
the deterministic contract digest; an unresolved result remains unresolved.
The builder consumes bound input and grants no execution or project eligibility.

Each validation ledger obligation must cite its own source. That source is
admissible only for that obligation; file, boundary and category evidence domains
retain their existing scope. Missing and duplicated obligations remain rejected.
Remediation origin reconstruction preserves the validation binding and its
authenticated findings-validation coverage hash.

This primitive does not yet project canonical obligations into every native review
context or close independent semantics. Mandatory lane admission and all context,
reuse, remediation and terminal consumers remain subsequent bounded work.
