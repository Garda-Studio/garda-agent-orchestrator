# Declared validation in review contexts

Generated review coverage now projects the canonical declared targets into the
required capable code/test lanes. The projection authenticates the current native
preflight, including custom artifact names, its retained bytes, frozen review
policy and canonical observed execution. Independent context validation rebuilds
the same targets rather than trusting a context digest or its target list.

Every declared target retains its exact source identity, selector, snapshot,
attempt and result. An authenticated remediation delta can narrow changed-file
coverage but does not remove declared validation obligations. Opaque UNRESOLVED
results remain execution facts requiring independent semantic inspection.

The findings template names each validation obligation's own source. Only that
coverage entry may cite an unchanged declared source outside the ordinary
changed-file domain; general notes, other coverage entries, findings and residual
risks retain their existing evidence domain and line checks.

Owning regressions exercise a genuine declaration, custom current preflight and
observed attempt, valid context reconstruction, omitted/stale target rejection,
and the narrow findings citation exception. Existing undeclared contracts retain
their shape. Reuse/audit continuation, terminal enforcement and global activation
remain separate dependent work.

The existing shared scope-only coverage builder retains its inspection contract
for pending navigation/audit callers. Strict projection is confined to current
review construction and independent context validation. Custom task-mode
artifacts are checked against genuine native entry identity; a conventional
default filename cannot substitute for that artifact.
