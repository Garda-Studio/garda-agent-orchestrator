# Native Original Parent Proof Qualification

The read-only parent-obligation resolver composes the accepted native graph and
child-source selector with existing command, memory and suspended-WIP readers.
It returns qualified observations or concrete blockers, never parent acceptance.

Every observed original full-suite command and coverage identity requires a
successful native intermediate command after child completion on the exact clean
final source. Commands are deduplicated by command and coverage identity. A later
failure cannot be replaced with an older successful invocation.

All original native WIP captures remain suspended and byte-verified, including
patch references, untracked files and tracked base blobs. Absence of a capture
does not invent a clean-parent custody record. Memory requires the original
preflight, current genuine parent impact evidence and its matching native
post-completion event. Child memory does not replace parent memory.

Historical suite or memory failures are resolved only by their corresponding
qualified original proof. Other historical failures remain explicit blockers.
Queue, decision, preflight and parent timeline are checked across consumption.

The focused unit fixture mocks the existing independently validated trust
readers, not the new resolver. It is not evidence of actual parent acceptance.
Integration with the real task audit belongs to the next bounded work package.
