# Contained parent-audit proof inputs

The parent-audit proof owner now reads an exact hash-bound JSON record through
the existing native contained-filesystem identity contract. The descriptor must
refer to the bound ordinary, unshared file; acquisition is nonblocking so a
replacement FIFO cannot wait indefinitely for a writer. Reads have a fixed
eight-MiB budget and reject content, size, identity or metadata drift.

The API verifies byte fidelity and record shape only. It does not authenticate
source acceptance, interpret terminal task rows, waive parent memory evidence,
sign historical artifacts or emit an aggregate PASS. Later bounded packages
retain those separate obligations and the original child/WIP/history evidence.

The owning regression covers exact ordinary UTF-8 reads, missing/stale/forged
digests, malformed or non-record JSON, resource bounds, foreign/traversal/linked
paths, same-byte replacement and growth during reading. A POSIX subprocess
replaces the final file with a writerless FIFO and requires rejection under a
finite external timeout. Linux gates are required; Windows/macOS execution is
unverified.
